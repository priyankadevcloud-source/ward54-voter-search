# Ward 54 Voter Lookup

Door-wise electoral roll search for **Guntur Municipal Corporation Ward 54** (same layout as the Ward 48 Claude artifact).

## Features

- Search by name, door number, EPIC
- Filter by polling station (`54/{part}`) and gender
- Voters grouped by door
- Stats: voters, doors, stations, gender counts

## Local

Open `index.html` in a browser, or:

```bash
python3 -m http.server 8765
```

Source: SEC Andhra Pradesh photo electoral roll. For reference lookup only.
